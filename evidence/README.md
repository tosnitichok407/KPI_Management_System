## สภาพแวดล้อมที่ทดสอบ

| รายการ | ค่า |

| เบราว์เซอร์ | Google Chrome 155 (headless) ควบคุมผ่าน DevTools Protocol — คลิก/เลือกไฟล์/ยืนยันจริง แล้วจับภาพหน้าจอ |
| ผู้ใช้ทดสอบ | `syn_emp1` (พนักงาน) · `syn_admin` (ผู้ดูแลระบบ) |

## วิธีทำซ้ำ (โดยสรุป)

1. ล็อกอินเป็นพนักงาน → เมนู "บันทึกผล KPI (Excel)"
2. เลือกปี 2026 เดือนมกราคม → เลือกไฟล์ `fixtures/synthetic-company-form-jan-feb.xlsx` → "ตรวจสอบไฟล์"
3. ตรวจ Preview → ติ๊ก "ยืนยันอัปเดตรายการนี้" ของรายการที่มี Draft เดิม → "ยืนยันนำเข้า"
4. ตรวจหน้าผลการปฏิบัติงานเดือนมกราคม (สถานะ Draft)

## หลักฐานจากไฟล์จริง (นอก Repository)

## สิ่งที่หลักฐานนี้ "ไม่ได้" แสดง

- ยังไม่ได้ทดสอบการกดนำเข้าผ่านหน้าเว็บบน **ฐานข้อมูลจริง (Production)** ด้วยบัญชีพนักงานจริง
  (การบันทึกบนฐานข้อมูลจริงที่ทำไปแล้วใช้คำสั่ง PHP ที่เรียกฟังก์ชันชุดเดียวกับหน้าเว็บ)
